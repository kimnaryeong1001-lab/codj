# 🌱 다정다감 (多情多感) - 청년과 어르신의 세대 공감 대화 플랫폼

청년의 활력과 어르신의 지혜가 만나 서로의 언어와 마음을 나누는 따뜻한 웹사이트입니다.

---

## 🌟 핵심 기능 소개

### 1. 역할 선택 로그인 & 맞춤형 UI
- **청년 세대 / 어르신 세대** 중 원하는 역할을 선택하여 입장할 수 있습니다.
- **어르신 맞춤 배려 모드**:
  - 어르신으로 입장 시 기본적으로 글씨 크기가 시원하게 확대됩니다.
  - 상단 **[🔍 어르신 큰글씨]** 버튼을 통해 언제든 큰 글씨 모드를 켜고 끌 수 있습니다.
  - 따뜻하고 편안한 오렌지/앰버 색감과 높은 가독성의 디자인을 제공합니다.

---

### 2. 세대 간 실시간 소통 & 다중 탭 연동
- **🤝 실시간 세대 나눔 광장**:
  - 브라우저 창이나 탭을 2개 띄워보세요.
  - **탭 A**는 '청년'으로, **탭 B**는 '어르신'으로 로그인하면 서로 실시간으로 메시지를 주고받을 수 있습니다 (`BroadcastChannel` 기술 적용).

---

### 3. 성격과 이름이 다른 3명의 세대별 AI 대화 친구
사람이 없거나 밤늦은 시간에도 언제든 대화할 수 있도록 각기 다른 개성을 가진 3명의 AI가 대기하고 있습니다:

1. **👵 김순자 어르신 (75세, 따스한 인생 멘토)**
   - *말투:* 구수하고 정 많은 할머니 말투 ("아이구 우리 젊은이 왔는가~", "밥은 잘 챙겨 먹고 다니고?")
   - *특징:* 취업, 시험, 인생의 고단함에 따뜻한 위로와 깊은 혜안을 건네줍니다.
   - *음성:* 차분하고 푸근한 중저음 음조.

2. **🧑‍💻 이민준 청년 (24세, 활기찬 대학생/취준생)**
   - *말투:* 싹싹하고 예의 바른 청년 말투 ("어르신 안녕하세요! 오늘 날씨 참 화창하죠?")
   - *특징:* 최신 트렌드와 스마트폰 팁을 친절히 안내하며, 어르신의 옛이야기와 지혜를 진심으로 배우고 존경합니다.
   - *음성:* 맑고 경쾌한 청년 음조.

3. **🤖 박바우 박사 (세대징검다리 AI 중재자)**
   - *말투:* 유쾌하고 지적인 중재자 말투 ("세대 차이는 장벽이 아니라 새로운 세상을 발견하는 기회입니다!")
   - *특징:* 청년 신조어와 어르신 옛말을 실시간으로 상호 번역해주고 갈등 없는 대화의 기술을 전수합니다.
   - *음성:* 또렷하고 신뢰감 있는 표준 톤.

---

### 4. 모르는 단어를 누르면 알려주는 세대 공감 사전
- 대화 중 상대방이 신조어나 생소한 고유어를 사용하면 **점선 배지 버튼으로 자동 감지 및 표시**됩니다.
- **단어를 클릭하면 귀여운 팝업 카드**가 열립니다:
  - 📖 **단어의 원뜻과 유래**
  - 🌱 **쉬운 세대별 해설**
  - 💬 **실제 대화 속 예문**
  - 🔄 **'상대방에게 쉽게 바꿔 말하면?'** 대체 표현 가이드
  - 🔊 **소리로 뜻 듣기** 버튼
- 우측 사이드바에서 언제든 궁금한 단어를 검색할 수 있는 사전 검색기도 제공됩니다.

---

### 5. 완벽한 음성 대화 기능 (STT & TTS)
- **🎤 음성으로 말하기 (Speech-to-Text)**:
  - 입력창 좌측의 마이크 버튼을 누르고 편하게 말씀하시면 글자가 자동으로 타이핑됩니다.
  - "전송" 또는 "보내기"라고 말씀하시면 자동으로 전송됩니다.
- **🔊 소리로 듣기 (Text-to-Speech)**:
  - 모든 말풍선 아래의 **[🔊 읽어주기]** 버튼을 누르면 친근한 한국어 음성으로 메시지를 낭독합니다.
  - 상단 **[자동 낭독 켜기]** 스위치를 켜두시면 메시지가 올 때마다 자동으로 읽어주어 눈이 피로하신 어르신들이 라디오처럼 들으실 수 있습니다.

---

## 🚀 실행 방법

### 방법 1: 로컬 웹서버로 실행 (추천 - 마이크 음성인식 100% 호환)
1. `c:\finish\start_server.bat` 파일을 더블클릭합니다.
2. 검은색 창이 뜨면서 자동으로 웹브라우저에서 `http://localhost:8080/`이 실행됩니다.

### 방법 2: 브라우저에서 바로 열기
1. `c:\finish\start.bat` 파일을 더블클릭하거나 `c:\finish\index.html` 파일을 크롬/엣지 브라우저로 드래그합니다.

---

## 📂 파일 구조
```
c:\finish\
│  index.html            # 메인 웹페이지 (HTML5 + Tailwind CSS)
│  start.bat             # 더블클릭 브라우저 실행 배치 파일
│  start_server.bat      # 로컬 웹서버 실행 배치 파일
│  start_server.ps1      # PowerShell 경량 HTTP 웹서버 스크립트
│  README.md             # 프로젝트 안내서
│
├─css\
│      style.css         # 어르신 모드, 애니메이션, 말풍선 커스텀 스타일
│
└─js\
       dictionary.js     # 세대별 사전 데이터 및 단어 자동 감지기
       ai-personas.js    # 3명의 AI 페르소나 지능형 대화 엔진
       speech.js         # Web Speech API (마이크 STT & 낭독 TTS)
       chat.js           # 실시간 브로드캐스트 & AI 대화 관리자
       app.js            # 메인 앱 상태 관리 및 이벤트 제어
```
